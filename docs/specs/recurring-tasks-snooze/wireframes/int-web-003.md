# INT-WEB-003 — Conclusão e histórico

```text
Painel da tarefa                         Histórico de ocorrências
┌──────────────────────────────────┐    ┌──────────────────────────────┐
│ Toda segunda · ocorrência aberta  │    │ Histórico de ocorrências      │
│ Data lógica: seg., 28 set         │    │                              │
│ Agendada para: ter., 29 set       │    │ 28 set · agendada 29 set     │
│ [Concluir ocorrência]             │    │ concluída em 30 set           │
│ [Histórico de ocorrências]        │    │ Toda segunda                  │
│ ⋯ Concluir definitivamente        │    │                              │
└──────────────────────────────────┘    │ 21 set · agendada 21 set     │
                                        │ concluída em 21 set           │
Confirmação                              │ [Carregar anteriores]         │
┌──────────────────────────────────┐    └──────────────────────────────┘
│ Concluir ocorrência de 28 set?    │
│ Data efetiva [30 set             ]│
│ Próxima prevista: segunda, 5 out  │
│ [Cancelar] [Concluir ocorrência]  │
└──────────────────────────────────┘
```

A conclusão normal anuncia a próxima ocorrência; a conclusão definitiva é confirmação separada e não usa o mesmo botão.
