# INT-WEB-001 — Editor de recorrência

```text
Desktop — painel da tarefa
┌──────────────────────────────────────────────────────┐
│ Planejamento                                           │
│ [Início] [Fim] [Duração]                               │
│                                                        │
│ Recorrência                         [● Ativa]          │
│ Expressão: [ toda segunda                 ] [Interpretar]
│ ✓ Toda segunda-feira · regra fixa                       │
│                                                        │
│ Frequência [Semanal v]  Base [Fixa no calendário v]    │
│ Dias          [Seg] [Ter] [Qua] [Qui] [Sex] [Sáb] [Dom]│
│ Início [ data ]        Término [ sem fim v ]           │
│ Próxima data lógica: segunda, 28 set                   │
│ Ocorrência atual: agendada para segunda, 28 set        │
│                                                        │
│ [Remover recorrência]       [Salvar recorrência]       │
└──────────────────────────────────────────────────────┘

Telefone — folha do painel
┌──────────────────────────────┐
│ ‹ Editar recorrência          │
│ Expressão                     │
│ [toda segunda               ] │
│ ✓ Toda segunda-feira          │
│ Frequência [Semanal         v]│
│ Dias [Seg] [Qua] [Sex]        │
│ Início [data]                 │
│ Término [Sem fim            v]│
│ Próxima: seg., 28 set         │
├──────────────────────────────┤
│ [Remover] [Salvar recorrência]│
└──────────────────────────────┘
```

Regiões: expressão e editor visual representam um único rascunho; resumo confirma a interpretação antes do salvamento; a confirmação permanece no rodapé do formulário.
